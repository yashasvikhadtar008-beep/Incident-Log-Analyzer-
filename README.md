# Incident-Log-Analyzer-
A beginner-friendly Python Log Analyzer that reads a log file, counts INFO, WARNING, and ERROR entries, and displays all error messages. This project demonstrates file handling, functions, loops, dictionaries, lists, and basic exception handling in Python.
# Python Log Analyzer

This is a simple Python project that reads a log file and gives a summary of the log entries.

I made this project to practice file handling and some basic Python concepts.

# What this project does

The program:

- Reads the `app.log` file line by line
- Counts the total number of valid entries
- Counts INFO, WARNING and ERROR entries
- Displays all the ERROR messages
- Skips empty lines
- Skips incorrect or malformed log lines
- Handles the case when the log file is not found

# Python Concepts Used

In this project I used:

- Functions
- File handling
- `for` loop
- `if-else` conditions
- Lists
- Dictionaries
- String methods
- `try-except`
- Basic exception handling
